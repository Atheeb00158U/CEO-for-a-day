# Course map banners

Each module on the course map has its own banner. The banner shows the module's core idea in a scene an Indian
player would recognise. Before this (Atheeb, 6 Nov 2026), a module showed its gate Hot Seat's cover, and a module
with no gate showed a plain gold block.

- **Made with:** ChatGPT, in one chat for a matching set, on 6 Nov 2026.
- **Masters:** `content/brand/modules/<module id>.webp` at 1440×600, cropped around the subject.
- **Served:** listed in `MODULE_BANNERS` (`src/lib/brand.ts`) and built by `npm run brand`.

## Style (in every prompt)

- **Look:** a realistic film still, 1990s–2010s India, warm amber and brass light, deep shadows, shallow depth of
  field.
- **Framing:** the main subject sits in the centre third, so the image survives the thin crop.
- **Never in the image:** text, readable words or numbers, logos, brand names, or a real person's likeness.
