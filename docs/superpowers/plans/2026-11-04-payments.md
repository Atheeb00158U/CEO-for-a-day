# Payments and paywall: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Take money with Razorpay Subscriptions:

- the founding plan, ₹99 a month for seats 1–500;
- then ₹199 a month or ₹1,499 a year.

Lock everything after Unit 1 for non-members, keep what early players finished, and allow a one-tap cancel.

**Architecture:**

- **Razorpay:** the server talks to Razorpay's REST API with `fetch` and Basic auth. No SDK, no new
  dependency.
- **Who is a member:** a `memberships` table, written only by the server: from the checkout's verified
  signature, and from webhooks whose HMAC is checked and which are handled once each (`payment_events`).
- **Seats:** handed out by a Postgres function under an advisory lock, held for 30 minutes at checkout and
  kept for good on the first charge.
- **Who may open what:** a pure function in `src/lib/access.ts` decides, from the course, the player's
  membership and their early-access snapshot. Four routes enforce it and answer 402 `members_only`. The
  phone shows the wolf's paywall sheet.
- **Switch:** with `PAYWALL_ON` unset, only accounts in `PAYWALL_TESTERS` are affected, so the whole flow is
  tested on Railway with test keys.

**Tech stack:**

- Next.js route handlers.
- Supabase Postgres (migrations through the Supabase MCP).
- `node:crypto` HMAC.
- Razorpay Checkout's script (`https://checkout.razorpay.com/v1/checkout.js`).
- Vitest.

**Spec:** `docs/superpowers/specs/2026-11-03-wolf-ambassador-design.md` §3, §4 and §4a.

**Branch:** `payments`, cut from `wolf-landing`. PR #9 (the landing page) and this one merge together.

**Every commit** ends with the implementing model's `Co-Authored-By` line. **Every task** ends with
`npm test`, `npx tsc --noEmit -p .`, `npm run lint` and `npm run format:check` green. Nothing is pushed until
Task 12.

**What Atheeb does (Claude never handles secrets or signs in):**

- In Razorpay's test mode, generate API keys and create the webhook, with a secret he types himself.
- Paste the variables into Railway.
- Check GST with his CA before going live.

Claude may create the three plans in the Razorpay dashboard, with his go-ahead at that step. Plan ids aren't
secret.

**Files:** create `supabase/migrations/20261104090000_payments.sql`.

- [ ] **Step 1: Write the migration.**

```sql
-- Payments (spec §4, §4a). Only the server touches these tables (secret key): RLS on, no policies, no grants.

-- A paid seat stays used for good: deleting an account keeps the seat with no owner, and cancelling marks it.
-- A checkout holds a seat for 30 minutes; the first charge clears held_until and the seat is kept.
alter table public.founding_seats alter column user_id drop not null;
alter table public.founding_seats drop constraint founding_seats_user_id_fkey;
alter table public.founding_seats
  add constraint founding_seats_user_id_fkey foreign key (user_id) references auth.users (id) on delete set null;
alter table public.founding_seats add column held_until timestamptz;
alter table public.founding_seats add column cancelled_at timestamptz;

-- One membership per player: the latest subscription. status mirrors Razorpay's subscription status.
create table public.memberships (
  user_id uuid primary key references auth.users (id) on delete cascade,
  plan text not null check (plan in ('founding', 'monthly', 'yearly')),
  razorpay_subscription_id text not null unique,
  status text not null,
  current_end timestamptz,
  updated_at timestamptz not null default now()
);

-- Webhooks are retried; each event id is handled once.
create table public.payment_events (
  event_id text primary key,
  received_at timestamptz not null default now()
);

-- Lessons and Hot Seats a player finished before the paywall: they stay open (filled once at go-live).
create table public.early_access (
  user_id uuid not null references auth.users (id) on delete cascade,
  kind text not null check (kind in ('lesson', 'hotseat')),
  item_id text not null,
  primary key (user_id, kind, item_id)
);

alter table public.memberships enable row level security;
alter table public.payment_events enable row level security;
alter table public.early_access enable row level security;
revoke all on public.memberships, public.payment_events, public.early_access from anon, authenticated;

-- Hold the lowest free seat for this checkout. Returns the seat number, or null when all 500 are taken.
-- A seat is free if it has no row, or only an expired, never-paid hold. One lock serialises every claim.
create or replace function public.claim_founding_seat(p_user uuid, p_subscription text, p_hold_minutes int default 30)
returns integer
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_seat integer;
begin
  perform pg_advisory_xact_lock(hashtext('founding_seats'));
  -- Free this player's own earlier, unpaid hold so a second checkout doesn't take two seats.
  delete from public.founding_seats where user_id = p_user and held_until is not null;
  -- Expired unpaid holds go back to the pool.
  delete from public.founding_seats where held_until is not null and held_until < now();
  select s into v_seat from generate_series(1, 500) s
    where not exists (select 1 from public.founding_seats f where f.seat_no = s)
    order by s limit 1;
  if v_seat is null then
    return null;
  end if;
  insert into public.founding_seats (seat_no, user_id, razorpay_subscription_id, held_until)
    values (v_seat, p_user, p_subscription, now() + make_interval(mins => p_hold_minutes));
  return v_seat;
end;
$$;
revoke all on function public.claim_founding_seat(uuid, text, int) from public, anon, authenticated;
```

```ts
// Who may open what (spec §4a): Unit 1 is free; members open everything; early players keep what they finished.
// Pure, shared by the server (enforcement) and the phone (lock badges). Node runs it too: no @/ imports.
import type { Course } from "./course-types";

export type ItemKind = "lesson" | "testout" | "hotseat";
export interface Item {
  kind: ItemKind;
  id: string;
}
export interface AccessContext {
  /** False while the paywall is switched off for this player (see paywallFor in server/membership.ts). */
  paywall: boolean;
  member: boolean;
  /** `lesson:<id>` and `hotseat:<id>` finished before the paywall. */
  early: Set<string>;
}
export interface MembershipLike {
  status: string;
  currentEnd: string | null;
}

export const FREE_UNIT = 0; // the first unit in course.json is free

export const keyOf = (item: Item) => `${item.kind}:${item.id}`;

export function freeItems(course: Course): Set<string> {
  const unit = course.units[FREE_UNIT];
  const out = new Set<string>();
  for (const m of unit?.modules ?? []) {
    out.add(`testout:${m.id}`);
    for (const l of m.lessons) out.add(`lesson:${l}`);
    for (const g of m.gates ?? []) out.add(`hotseat:${g}`);
  }
  return out;
}

const PAID_UNTIL_END = new Set(["active", "authenticated", "pending", "halted", "cancelled", "completed"]);

/** A member is active now, or cancelled or behind on a payment while the paid period runs. */
export function isMember(m: MembershipLike | null, now: Date): boolean {
  if (!m) return false;
  if (m.status === "active") return true;
  return PAID_UNTIL_END.has(m.status) && !!m.currentEnd && new Date(m.currentEnd) > now;
}

export function canOpen(item: Item, ctx: AccessContext, free: Set<string>): boolean {
  if (!ctx.paywall || ctx.member) return true;
  const key = keyOf(item);
  return free.has(key) || ctx.early.has(key);
}
```

Check that `Course` is the type `course.json` parses to (`src/lib/course-types.ts`) and that `unit.modules`,
`m.lessons` and `m.gates` are named as shown; adjust the field names if not, and say so.

```ts
// Razorpay Subscriptions over REST (no SDK). Keys live only in Railway; nothing here reaches the browser.
// Docs: https://razorpay.com/docs/api/payments/subscriptions/ and webhook validation.
import { createHmac, timingSafeEqual } from "node:crypto";

const API = "https://api.razorpay.com/v1";

function same(a: string, b: string) {
  const x = Buffer.from(a, "utf8");
  const y = Buffer.from(b, "utf8");
  return x.length === y.length && timingSafeEqual(x, y);
}
const sign = (secret: string, s: string) => createHmac("sha256", secret).update(s).digest("hex");

export const checkoutSignatureOk = (p: { paymentId: string; subscriptionId: string; signature: string }, keySecret: string) =>
  same(sign(keySecret, `${p.paymentId}|${p.subscriptionId}`), p.signature);

export const webhookSignatureOk = (rawBody: string, signature: string | null, webhookSecret: string) =>
  !!signature && same(sign(webhookSecret, rawBody), signature);

export interface RazorpayClient {
  createSubscription(planId: string, totalCount: number, notes: Record<string, string>): Promise<{ id: string; status: string }>;
  cancelSubscription(id: string, atCycleEnd: boolean): Promise<{ status: string; current_end: number | null }>;
}

export function razorpay(keyId = process.env.RAZORPAY_KEY_ID, keySecret = process.env.RAZORPAY_KEY_SECRET): RazorpayClient {
  if (!keyId || !keySecret) throw new Error("Razorpay keys are not set");
  const auth = "Basic " + Buffer.from(`${keyId}:${keySecret}`).toString("base64");
  const call = async <T>(path: string, body: unknown): Promise<T> => {
    const r = await fetch(API + path, {
      method: "POST",
      headers: { Authorization: auth, "Content-Type": "application/json" },
      body: JSON.stringify(body),
      signal: AbortSignal.timeout(10_000),
    });
    const data = await r.json().catch(() => ({}));
    if (!r.ok) throw new Error(`Razorpay ${path} ${r.status}: ${data?.error?.description ?? "error"}`);
    return data as T;
  };
  return {
    createSubscription: (planId, totalCount, notes) =>
      call("/subscriptions", { plan_id: planId, total_count: totalCount, customer_notify: 1, notes }),
    cancelSubscription: (id, atCycleEnd) => call(`/subscriptions/${id}/cancel`, { cancel_at_cycle_end: atCycleEnd ? 1 : 0 }),
  };
}
```

Check the request and reply fields against Razorpay's current Subscriptions API docs (Context7 or their docs

unix seconds. Fix any name that differs, and say which.

### Task 5: `src/lib/server/membership.ts`, the payment logic

**Files:** create `src/lib/server/membership.ts` and `src/lib/server/membership.test.ts`.

Functions (take `db`, an injected `RazorpayClient`, the env as a small `PayEnv` object, and `now`, so
tests use `memoryDb()` and a fake client):

- `type Plan = "founding" | "monthly" | "yearly"`.
- `PayEnv = { keyId, keySecret, plans: Record<Plan, string>, totalCount: Record<Plan, number> }`. Read it
  once from `RAZORPAY_*` variables in `payEnv()`. `totalCount`:
  - founding and monthly: 120 (ten years of months; renewal is automatic while the mandate lasts);
  - yearly: 10.
- `startCheckout(db, rp, env, userId, plan)`:
  1. A current member gets `GameError("Already a member")`.
  2. For a founding checkout:
     - check `cachedSeatStatus` is still open; if not, `GameError("Founding seats are full")`;
     - create the subscription, then `db.claimSeat(userId, sub.id)`;
     - if that returns null (a race), cancel the subscription at once (`atCycleEnd = false`) and throw the
       same GameError.
  3. Monthly and yearly checkouts create the subscription directly.
  4. Save the membership with `status: "created"` and `currentEnd: null`.
  5. Return `{ subscriptionId, keyId }`.
- `confirmCheckout(db, env, userId, { paymentId, subscriptionId, signature })`:
  1. Verify the signature, or `GameError("Payment not verified")`.
  2. The membership must belong to this user and this subscription.
  3. Set `status: "authenticated"` and `currentEnd` = now + 35 days (or + 370 for yearly) as a temporary
     end, so the player is in at once. The webhook then sets the real `current_end`.
  4. For founding, `keepSeat`.
  5. Return the membership.
- `handleWebhook(db, env, rawBody, signature, eventId)`:
  1. A bad signature: return `{ ok: false, status: 400 }`.
  2. `insertPaymentEvent(eventId)` false: return `{ ok: true }` (a duplicate).
  3. Parse `payload.subscription.entity` (`id`, `status`, `current_end`) and find the membership by
     subscription id. If none is found, return `{ ok: true }` (not ours).
  4. Map the events:
     - `subscription.activated` and `subscription.charged`: status from the entity, `currentEnd` from
       `current_end`, and `keepSeat` for founding;
     - `subscription.pending` and `subscription.halted`: status only (they keep access until `currentEnd`);
     - `subscription.cancelled` and `subscription.completed`: status, plus `cancelSeat` for founding.

     Ignore other events.
  5. Then `forgetAccess(userId)` (Task 6's cache).
- `cancelMembership(db, rp, userId)`:
  1. No membership, or already `cancelled`: `GameError("No active membership")`.
  2. Otherwise `rp.cancelSubscription(id, true)`, then save `status: "cancelled"`, keeping `currentEnd`. The
     player keeps access to the end of the period. For founding, `cancelSeat`.
